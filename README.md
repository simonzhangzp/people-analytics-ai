# PeopleAnalyticsAI

Public site for [peopleanalyticsai.net](https://peopleanalyticsai.net).

Enterprise People Data & AI case studies on a frozen synthetic GlobalTech
dataset (`data-v1`, as-of 2026-08-31). Numbers are generated by a seeded
simulator. They are not a customer’s employees.

Primary navigation: Home, Enterprise Demo, Architecture, Perspective, About.
Footer: Enterprise Demo, Architecture, Connect via MCP, Dataset.

The early file-analysis experiment (`/lab`, `/workbench`, `/app`, Formulator)
is retired. Those URLs 301 to `/`.

New agents: start with `docs/AGENT_BRIEFING.md` (live scope, recruiter walk,
paste-ready prompt). Do not treat architecture §6 as shipped; use §11.
