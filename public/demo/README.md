# Synthetic Workbench demo data

These files are generated by `scripts/generate_workbench_demo.py`. They contain
no real employee data or direct identifiers.

Embedded test signal:

- Engineering voluntary attrition: 9.2% → 13.7% (+4.5 percentage points);
- 2–4 year tenure: 61 of 90 incremental exits (67.8%, displayed as 68%);
- current exits are more concentrated at L5–L6;
- lower compensation positioning is associated with higher exit incidence;
- retirement is present as a separate classification decision;
- manager effectiveness is intentionally absent.

The identifiers are deterministic synthetic keys used only to exercise local
joins. Raw rows remain in the browser when the demo runs.
